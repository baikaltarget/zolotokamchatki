# Инструкция
Проверь App Router metadata, canonical, robots и sitemap, HTML без клиентского JS, alt и размеры изображений, CLS, редиректы, ссылки и корректность JSON-LD. Не применяй жёсткие лимиты знаков для title/description. Проверь доступные build/typecheck/lint; явно отмечай непройденные проверки.
