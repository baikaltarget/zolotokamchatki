Очередь публикации. Сайт эту папку не читает.

Робот (.github/workflows/publish.yml) каждый день в 09:00 по Иркутску переносит отсюда в content/blog/ статьи, у которых дата в шапке уже наступила, и отправляет их в Яндекс.

Чтобы добавить статью в очередь: положите .md сюда с нужной датой в поле date.
Чтобы опубликовать раньше: поменяйте date на сегодня — утром робот заберёт.
Чтобы опубликовать прямо сейчас: Actions → Scheduled Publish → Run workflow.
